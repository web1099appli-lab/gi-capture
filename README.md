# GI-Capture

**L'enregistreur d'écran gratuit pour créer vos tutoriels YouTube.** Application Windows 10 / 11 (64 bits).

GI-Capture filme votre écran, votre voix et votre webcam, vous laisse dessiner sur l'écran pendant
l'enregistrement, puis produit une vidéo MP4 prête pour YouTube. Elle ne se connecte jamais à internet.

## Télécharger

👉 **[Dernière version](https://github.com/web1099appli-lab/gi-capture/releases/latest)** :
`GI-Capture-Setup-x.y.z.exe` (installeur) ou `GI-Capture-Portable-x.y.z.exe` (sans installation).

Le logiciel n'est pas signé par un certificat payant : si Windows affiche « Windows a protégé votre
ordinateur », cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.

## Fonctions

- Filmer un **écran entier**, une **fenêtre** ou une **zone personnalisée** (Maj = format 16:9)
- **Son de l'ordinateur + micro** mélangés, volumes séparés, VU-mètre et réduction du bruit
- **Webcam incrustée** (ronde ou rectangulaire, S/M/L, miroir, déplaçable)
- **Dessin à l'écran** pendant l'enregistrement : stylo, surligneur, flèche, rectangle, 5 couleurs
- **Pause / reprise**, compte à rebours, **captures d'écran** PNG
- Barre de contrôle flottante **invisible dans la vidéo**
- Export **MP4 H.264 + AAC** (30/60 ips, natif / 1080p / 720p, 3 niveaux de qualité)
- **Bibliothèque** des enregistrements

## Raccourcis clavier

| Touches | Action |
|---|---|
| Ctrl+Alt+R | Démarrer / arrêter |
| Ctrl+Alt+P | Pause / reprise |
| Ctrl+Alt+D | Dessiner à l'écran (Échap pour sortir, Ctrl+Z pour annuler un trait) |
| Ctrl+Alt+W | Webcam |
| Ctrl+Alt+S | Capture d'écran |
